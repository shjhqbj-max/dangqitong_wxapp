# 团队模块设计文档

## 概述

档期通小程序团队模块，实现团队档期协同 + 成员管理功能。

## 核心功能

- **档期协同**：查看团队成员档期状态（谁有空/谁忙），方便协调排班和派单
- **成员管理**：查看成员列表、职业、角色，邀请/移除成员、修改权限

## 页面清单

| 页面 | 路由 | 说明 |
|------|------|------|
| 团队主页 | `pages/team/list` | 周日历 + 成员档期状态（已有 stub，重建） |
| 成员管理 | `pages/team/members` | 成员列表 + 权限操作（新建） |

## 数据流

```
teamApi.getMyTeams() → 顶部团队下拉切换
       ↓ 选择 teamId
teamApi.getTeamMembers(teamId) → 成员列表
       ↓ 用户选日期
getTeamSchedule(teamId, date) → 成员当日档期状态
```

### 交互细节

- **团队切换器**：点击展开下拉列表，显示团队名 + 成员数 + 角色，选中收起
- **周日历**：当前周高亮今天，左右箭头翻周，点击选日期
- **已排期成员卡片**：头像 + 昵称 + 职业 + 档期时间/状态
- **空闲成员**：只显示昵称和职业，紧凑排列
- **右上角管理**：跳转成员管理页

### 权限逻辑

| 操作 | admin | member |
|------|-------|--------|
| 查看成员 | ✓ | ✓ |
| 修改角色 | ✓ | ✗ |
| 移除成员 | ✓ | ✗ |
| 复制邀请码 | ✓ | ✓ |
| 退出团队 | ✗ | ✓ |

### 成员操作弹窗（admin 点击 ⋮）

- 设为管理员 / 取消管理员
- 移出团队
- 查看档期（跳转团队主页定位到该成员）

## 新增 API

| API | 说明 |
|-----|------|
| `getTeamSchedule(teamId, date)` | 按日期获取团队成员档期 |
| `updateMemberRole(teamId, userId, role)` | 修改成员角色 |
| `removeMember(teamId, userId)` | 移除成员 |
| `leaveTeam(teamId)` | 退出团队 |

## 新增类型

```ts
interface TeamScheduleItem {
```
